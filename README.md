# Fitness Tracker

## Overview

Fitness Tracker is a web application that allows users to record
their workouts and monitor their fitness progress.

The application is designed for individuals who want to track
activities such as swimming, running, biking, and weightlifting.

## Features

- Log workouts
- Record workout name and type
- Record workout date
- Track workout duration
- Track distance in miles
- Record sets, reps, and weight
- View workout history
- Delete recorded workouts
- View dashboard statistics
- Save workout data using browser localStorage

## Uses

- HTML
- CSS
- JavaScript
- Browser localStorage

## How to Run

1. Download or clone the repository.
2. Open the fitness-tracker folder.
3. Open index.html in a web browser.
4. Begin logging workouts.

##Storage

Workout information is stored locally in the user's browser
using JavaScript localStorage.

Saved workouts remain available after refreshing the page
or restarting the browser, provided the browser's stored
data is not cleared.
